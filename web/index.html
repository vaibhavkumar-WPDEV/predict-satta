Kaise use kare

  1. Kuch feed nahi karna. Server chalte hi tool khud result websites se Jan 2021 se aaj tak (5 saal) ka data laata hai, aur har 15 minute me naya result check karta hai.
  2. Aaj ke results (sabse upar): har market ka result time, countdown, aur result aate hi asli number + HIT/MISS.
  3. Aaj ki Prediction tab: har market ki agle result ki Top-10 jodi, Andar/Bahar top-3 aur tool ke khud ke formule. Har prediction result se pehle lock hoti hai, uska SHA-256 hash aur time likha hota hai.
  4. Proof (Live) tab: result aane ke baad tool khud milata hai — HIT/MISS, actual number ka rank, aur "kyu galat hua / kya seekha".
  5. 7-Din Test: pichle 7/30/100/200/saare din ka walk-forward test — har din sirf us din se pehle ka data use hua, jaise live me hota.
  6. Learning: 28 models (Bayes, Markov, Fourier, Kaplan–Meier, chaos theory, universal prediction (CTW), neural network, genetic programming, Aryabhata kuttaka, Fibonacci/golden ratio, Vedic beejank / Tesla 3-6-9, Einstein random walk, khud ke formule...) ke weights har result ke baad badalte hain (Fixed-Share Hedge + meta-learning + linear/geometric merge). "Seekhne ka asar" aur "Khud ko todo" test bhi yahin hain.
  7. Formule aur Theorems: tool ke khud dhoondhe formule aur statistical findings, unseen data par test karke.

Accuracy kaise padhein

Har number ke liye random chance: exact = 1%, top-10 = 10%, Andar/Bahar top-3 = 30%. Tool apni accuracy hamesha isi se compare karta hai. p-value chhota (< 0.05) ho tabhi maana jaye ki tool chance se behtar hai; warna result sirf kismat hai.

Commands

pip install -r requirements.txt
python -m satta serve                 # dashboard: http://localhost:8000
python -m satta cycle                 # ek baar: fetch → check → seekho → predict
python -m satta backtest --days 7     # Faridabad ka 7 din ka test
python -m satta table                 # Jan 2026 se aaj tak ka table
python -m satta verify                # predictions ka hash proof check
Numbers statistical estimates hain, guarantee nahi. Tool apni asli accuracy random chance se compare karke dikhata hai.
